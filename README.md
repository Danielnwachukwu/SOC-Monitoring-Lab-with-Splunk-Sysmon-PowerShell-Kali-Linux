# SOC-Monitoring-Lab-with-Splunk-Sysmon-PowerShell-Kali-Linux
Windows endpoint monitoring and threat detection lab built with Splunk Enterprise, Sysmon, PowerShell, and Kali Linux. Demonstrates SIEM log ingestion, PowerShell activity detection, Sysmon event monitoring, network enumeration, SPL querying, event visualization, and SOC analysis workflows.
